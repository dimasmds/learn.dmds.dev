# learn.dmds.dev — Project Overview

## Visi

Platform microlearning gratis untuk belajar pemrograman dari nol, berbahasa Indonesia, dengan pengalaman belajar yang terasa seperti bermain game.

## Target User

Pemula total yang belum pernah menulis kode sebelumnya.

## User Success

User bisa membangun web interaktif sederhana dengan HTML, CSS, dan JavaScript — dengan use case yang real dan memang ada kebutuhannya.

## Benchmark

**Mimo** — platform microlearning coding terdepan dengan 35 juta learners. Pendekatan step-by-step, timer per step, dan gamifikasi menjadi acuan utama.

## Prinsip Desain

1. **Project-first pedagogi** — dari hari 1 langsung bikin sesuatu, konsep dipelajari sambil jalan
2. **Microlearning** — setiap lesson 5-10 menit, 1 tujuan pembelajaran per step
3. **Gamifikasi** — streaks, XP, badges untuk menjaga motivasi
4. **Interaktif** — user aktif menulis/memanipulasi kode, bukan pasif membaca
5. **Bahasa Indonesia** — semua konten, UI, dan feedback dalam Bahasa Indonesia
6. **100% gratis** — tidak ada paywall

## Scope MVP

- Konten: HTML, CSS, JavaScript dasar
- Capability: User bisa bikin web interaktif sederhana
- Platform: Web app (mobile-first)
- Auth: Diperlukan untuk progress tracking dan gamifikasi
